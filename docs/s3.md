# S3 Examples

## AWS S3

```yaml
nexus_storage_type: s3

nexus_storage_s3:
  enabled: true
  region: us-east-1
  bucket_prefix: prod-nexus
  access_key_id: "{{ vault_aws_access_key }}"
  secret_access_key: "{{ vault_aws_secret_key }}"
  endpoint: ""
  path_style_access: false
  encryption: KMS
  sse_kms_key_id: "{{ vault_kms_key_id }}"
  max_error_retry: "5"
```

## S3 with IAM Role

```yaml
nexus_storage_type: s3

nexus_storage_s3:
  enabled: true
  region: us-east-1
  bucket_prefix: prod-nexus
  access_key_id: ""
  secret_access_key: ""
  assume_role: "arn:aws:iam::123456789012:role/nexus-role"
  endpoint: ""
```

## S3 with STS Session

```yaml
nexus_storage_type: s3

nexus_storage_s3:
  enabled: true
  region: us-east-1
  bucket_prefix: prod-nexus
  access_key_id: "{{ vault_sts_access_key }}"
  secret_access_key: "{{ vault_sts_secret_key }}"
  session_token: "{{ vault_sts_session_token }}"
  expiration: "2024-12-31T23:59:59Z"
```

## S3 Buckets

```yaml
nexus_buckets:
  - name: prod-nexus-default
    versioning: false
    lifecycle:
      - expiration_days: 90

  - name: prod-nexus-docker
    versioning: true
    lifecycle:
      - expiration_days: 180
      - noncurrent_expiration_days: 30
```

```bash
# Validate S3 configuration
ansible-playbook -i inventories/production/inventory.yml playbooks/nexus_validate.yml --tags storage,s3
```
